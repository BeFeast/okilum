# Give multiline TextView link tooltips secondary detail text

Patch 0042 refines the application-owned `LinkTooltip` introduced by 0018 and
shared with the external-link marker by 0029. A tooltip such as
`File not found\n/home/god/missing-787.json` previously rendered both lines with
one style. It now renders the first line normally and subsequent lines as muted
12 px details in a vertical layout, retaining the existing maximum width.
Single-line tooltips retain their content; link hit geometry, hover ownership,
click policy and selection do not change. GPUI core is unchanged.

Reproduction: use `TextView::link_presentation` to supply the two-line tooltip
above, then hover the linked text. The detail should remain readable but visually
secondary. The same rendering is used by the external-link marker's host/URL
presentation. This is a follow-up to the pending TextView link-presentation and
hover APIs, rather than an independent patch against a base without those APIs.

Validation: the full pinned patch stack verifies, and application test targets
compile on Linux and MSVC. Native light/dark screenshot evidence is tracked in
Tessera #787; the before fixture and QA steps are recorded in its PR.
