# Configurable scrollable end space for TextView

> **Historical document.** Written before Tessera was renamed Okilum (2026-10-09). Names, paths and links are kept as they were then.

Pending upstream submission.

Patch 0024 adds bottom_padding to TextViewStyle, defaulting to zero, and applies
it to the internal virtualized list. Outer element padding reduces the viewport;
it cannot provide scrollable space after the final block. The base API offers a
builder/accessor and clamps negative values; the component style forwards the
value. Style equality includes it so resizing updates layout; changing only end space
does not advance the text selection revision or clear existing selection.

Tessera uses max(120px, 30% window height) for long-note reading and the existing
editor scroll-beyond-last-line API for source editing. Rendered tests scroll to
the end at 700px and 1000px window heights and assert the measured final-block
and final-line gaps. No source text is appended and no gpui core changes.
