# Lazy code display language

Pending upstream submission. Adds an optional display-language resolver shared by
code actions and syntax highlighting. Resolve once when block bounds intersect
the viewport; cache matches and abstentions by resolver identity. Language changes
invalidate highlight spans without changing source/selection/copy metadata.

The opt-in resolver reserves a header strip before inference, avoiding geometry
changes after a block becomes visible. Markdown fenced/indented provenance is
exposed so downstream inference can exclude indented prose. GPUI core is unchanged.
