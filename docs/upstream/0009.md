# Preserve paired original source in select-all clipboard copy

Applications may render a transformed Markdown document while Source copy should
return its authored body. `TextViewState::set_text_with_source` accepts rendered
input and optional exact select-all Source text together. Pending metadata follows
the parse revision; displayed metadata changes only when the parsed tree is
accepted. Late results cannot replace a newer pair. Identical rendered input can
still update its authored spelling, and extension-only reparsing preserves it.
Unpaired `set_text` or nonempty append invalidates the override with its update.
An error view cannot copy the retained previous document after a parse failure.

The owning TextView Copy action writes this exact Source selection before shared
selection joining/trimming. This preserves leading/trailing and whitespace-only
content. Plain, HTML and partial selection retain their existing behavior.

Tests cover asynchronous replacement and superseded results, same-input spelling
updates, unpaired invalidation, extension reparse, find navigation, Plain/HTML
boundaries and actual Copy-action clipboard contents with a positive control.

This follow-on patch builds on 0008; cumulative vendor verification applies both
in order. No gpui core patch and no inverse map for arbitrary partial selections.
