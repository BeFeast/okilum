# Report hover events for inert links

Follow-up to the pending TextView hover API in [0029](0029.md), required by
Tessera #546. Inert links still have useful hover actions (for example, offering
to create a missing document). Emit hover events for them and let the application
choose its preview. Click and selection guards remain unchanged.

Reproduction: render a missing wikilink, hover its exact text bounds, and show a
Create note action without navigating or changing selection. Tessera's native
hover test exercises pointer entry and the Create button; the existing inert
pointer test guards ordinary click behavior. The patch removes one filter;
GPUI core is unchanged. Upstream submission belongs with the pending 0029 API,
which is not yet present on upstream main.
