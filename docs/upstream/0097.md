# Scroll opening document space with the first block

A Reader that toggles outer padding when scrolling starts moves every painted
block by the padding amount, beyond the wheel delta. Okilum #1901 reproduces
this with a one-pixel wheel event: the logical list offset advances by one pixel,
but text moves by 45 pixels because the opening 44 pixels disappear.

Add optional `top_padding` to the Base and component TextView styles. Its default
is zero. For a virtualized document, the space belongs to the first measured
block, including shape-ahead measurements, and scrolls out with that block.
Non-scrollable documents apply the same opening space to their content.
No GPUI core changes or new dependencies are needed.

The application regression sends real pixel wheel events through the text column
and surrounding margin, crosses the top boundary in both directions, and asserts
the position of the same painted source anchor after ordinary Reader repaints.
It installs the production UI store and checks nonzero logical scrolling, so a
missing event or missing repaint cannot pass as smooth motion.
