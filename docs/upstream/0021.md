# GFM table rows share the header column count

> **Historical document.** Written before Tessera was renamed Okilum (2026-10-09). Names, paths and links are kept as they were then.

Upstream PR: https://github.com/longbridge/gpui-kit/pull/3365

Patch `0021-table-header-column-count.diff` normalizes parsed body rows to the
header/delimiter alignment count before measuring or rendering cells. Missing
cells are empty; excess cells are ignored. This keeps the existing shared column
widths consistent across all rows in both table layouts.

Tessera #376 reproduces the problem with three columns, several alias links in
one cell, long wrapping text and ragged body rows. The canonical fixture is
`fixtures/reader/table-alias-columns.md`. Parser coverage lives in the patch;
a downstream GPUI test exercises the rendered TableData through the Reader style.
No gpui core change is required.
