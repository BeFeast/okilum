# Opt-in outer-list inset for document typography

An outer Markdown list starts its marker gutter at the paragraph edge, while
nested lists already advance by one rem. Okilum feedback #2239 requests a visual
indent for bullet and numbered lists; changing source indentation would change
Markdown nesting instead of fixing that layout.

Expose `root_list_indent` on the Base and component rich-text styles, including
component-to-Base conversion and style equality. The default is zero, preserving
other consumers. Apply it once to lists at depth zero, as padding within their
available width. Existing nested-list margins, marker gutters, continuation
paragraphs, task controls and inline wrapping remain intact. Okilum's Reader
document style opts into one rem, matching the existing nested-list spacing.

Regression uses the real scrollable Markdown renderer and recorded shaped-text
positions: numbered/bullet lists, mixed nesting and long wrapping items all move
by one rem, while adjacent paragraphs remain fixed. Wrapped rows still start
under their own text, nested lists retain their extra step and source-copy bytes
stay unchanged. A zero-inset consumer provides the positive layout control.

This is a ready-to-paste upstream proposal, not an upstream submission; follow
the attributed process in [README.md](README.md). GPUI core is unchanged.
