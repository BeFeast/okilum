# Optional external-link marker in rich text

Pending upstream submission; applies after the current table wrapping patches.

LinkPresentation gains an opt-in external flag. An external marker occupies a
small inline-flow slot, participates in wrapping, and shares its link target and
tooltip. Text fragments retain offsets into the original InlineState for search;
the marker is not a text fragment and therefore does not enter selection/copy.
Fragment selections map back to the parsed run, preserving partial copy and
retained selection across redraws. Parsed reference definitions remain in the
render context (and accumulate on append).
Both normal paragraphs and table wrapping use the same path. Reference links
resolve presentation from their target, and adjacent styled parts of one link
get one marker. Missing/inert links retain existing presentation.

Downstream tests exercise reference-link marker clicks, copying without marker
text, internal-link absence, and snippets with repeated Unicode labels and
truncation. No gpui core changes.
