# Persistent overflow cues for Markdown tables

Pending upstream submission; follows patches 0019 and 0022 in the current stack.

A horizontally clipped table can appear complete when the cut falls through an
empty cell. Patch 0023 adds foreground-tinted inner shadows at clipped edges,
removes the outer border/radius at those edges, and paints a persistent 3px
scroll track whose thumb tracks the visible fraction and position. The existing
actions hook moves above overflowing tables so applications can supply a quiet,
always-visible column-count Expand badge without obscuring header content.
Tables that fit retain the actions hook below their content and get no cues.

The post-layout probe compares offset and viewport width as well as edge state;
this updates the thumb after scrolling and resizing without an idle redraw loop.
Tessera rendered coverage: wide_table_persistent_cues_follow_scroll_and_expand,
including empty cells, middle/end scroll positions, a working Expand action and
a narrow-table positive control. No gpui core changes.
