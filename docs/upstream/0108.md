# 0108: index native text ranges and caret boundaries on the rope

The platform requests the caret's native UTF-16 range during paint. Converting
the whole note to a String for every request makes that frame work grow with
the note. Projected caret movement also segmented the whole note into
graphemes for each boundary lookup.

Use the rope's UTF-16 index for native ranges and round-trip the byte offset
to reject a position inside a surrogate pair. Segment only the caret's line,
including its final LF, for projected grapheme boundaries: a grapheme cannot
continue across LF (UAX #29 GB4/GB5). Both paths keep the existing rejection,
boundary and bias behavior without flattening the note.

This patch modifies only the input state's native-range conversion and
projected cursor-boundary methods. It follows the source/projection patches
and commutes with patches 0103–0107; those patches do not modify these methods.
Its position after them preserves the same cumulative vendor tree. GPUI core
is unchanged.
