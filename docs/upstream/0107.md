# 0107: expose source-keyed scroll anchors for bounded message disclosures

Applications that collapse a message group must preserve the same retained row
and its pixel offset while the virtual list changes topology. A nested group
also needs to suspend tail following without discarding its reading position.

This patch exposes three thin MessageScrollerState methods over existing GPUI
ListState APIs: logical_scroll_top, pause_follow and scroll_to_offset. The caller
maps the returned item index to its own stable source identity. Restoring an
invalid index returns false. Explicit restoration leaves following disabled;
the caller may rearm it after disclosure settles and the end is still visible.
No message data is copied, and GPUI core is unchanged.

The Okilum G04/G05 regression exercises real click, Enter/Space and wheel input,
1000 bounded nested members, interior collapse/reopen anchors, append/status
updates and delayed output-height changes. The patch also supports the outer
source anchor during the two-frame disclosure settle period.

This is the ready-to-paste upstream proposal. It has not been submitted upstream;
see README.md for the attributed submission process and pinned-stack context.
