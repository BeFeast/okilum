# TextView link hover events

Issue: #446 (internal note previews).

Patch 0029 adds `TextView::on_link_hover` to Base and the Component compatibility
wrapper. Inline text reports pointer entry/exit using the same exact text-layout
link geometry as clicks; linked inline images report hover too. The callback is
owned by TextViewState, so nested Markdown parts share the containing view's
policy. It does not consume input or alter link selection/click semantics.
GPUI core is unchanged. Intended upstream API: a hover callback for applications
that need richer link previews than a string tooltip.
