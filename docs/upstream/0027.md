# Exact code-block copy content

Pending upstream submission. CodeBlock exposes optional `copy_code`, preserving
mdast's code indentation and restoring the terminal line ending from its source
span. Markdown delimiters and container indentation are excluded; LF, CRLF and
CR remain unchanged. Math/frontmatter/expression nodes have no copy payload.
Payload changes participate in block equality so retained blocks cannot copy
stale bytes after an otherwise visually identical replacement.

A `code-block` hover group lets downstream actions use the existing top-right
code_block_actions slot. Tessera supplies the keyboard-accessible Copy action
and transient feedback. No gpui core changes.
