# 0122: narrow projected container gutters

Follow-up to [0103](0103.md), tracked by Okilum #1641 and #1814.

0103 abandoned continuation indentation when the prefix exceeded half the
wrapping width or wrapped before the body. Deep lists then lost alignment,
and nested quote bars disappeared on continuation rows.

Shape the body at the width remaining after a bounded indent (at most half the
editor width), keeping the complete prefix on the first row. Store the excess
prefix width as `LineItem::prefix_hang`; paint and unpainted caret/hit geometry
subtract it from the first row and the continuation indent. Quote bars reuse
that same first-row offset. Prefix bytes and canonical source stay unchanged;
excess nesting clips to the left rather than consuming the text's available
width. Source mode, heading hangs and bidirectional paragraphs keep their paths.

GPUI core is unchanged. The existing indent cache key already includes prefix,
font and wrapping width. Shell GPUI regressions cover narrow/deep geometry,
actual quote-bar quads and >64 KiB Reader Live Preview caret entry/exit with
positive controls. Vendor tests still exercise Source wrapping and movement.
