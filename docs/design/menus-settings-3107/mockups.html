Tradeoffs and what remains to decide

A keeps a familiar Settings window and moves infrequent commands into secondary categories. B offers task entry points, but each setting still needs one canonical home. C favors search and needs clear result types to distinguish an action from a preference.

All three keep native macOS conventions, Windows and Linux access, keyboard navigation, explicit feature setup and the existing file ownership rules. Oleg has not chosen an alternative. None of these examples installs or changes Okilum.
