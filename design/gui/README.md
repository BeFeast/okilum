# Okilum app design

A three-pane desktop workspace inspired by the supplied 1Password reference: neutral navigation, a persistent goal/source list and a spacious selected-item view. Consistent rounded buttons distinguish primary, secondary and toolbar actions; exact Markdown stays connected to discussion, delegated stages and retained results. This is a reviewable design proposal with synthetic interactions, not the native Okilum application.

Open `prototype/index.html` directly in a browser. No backend, credentials or build tool is required. Source files are editable. Browser state is disposable demonstration state; restarting the prototype is not evidence of native persistence or backend recovery.

Current alpha capabilities, proposed UI arrangement and future concepts are labeled separately. Mobile capture/attention, semantic retrieval, Live Preview, automatic merge, AI context export, Maestro and Todoist replacement are future scope.

Repository-relative contract links in the specifications resolve in the full Okilum checkout. The downloadable design package contains this GUI proposal only; it does not duplicate production contracts or app source.
